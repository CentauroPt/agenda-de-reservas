🔗 Ligação ao Google Calendar

A aplicação fala diretamente com a API do Google a partir deste browser. Aqui fica apenas o Client ID, a API key e o ID do calendário — nenhum segredo é enviado para servidores nossos.

Desligado

1. Preparar no Google Cloud (só uma vez)

  1. Cria um projeto em console.cloud.google.com.
  2. Ativa a Google Calendar API nesse projeto.
  3. Em OAuth consent screen, escolhe External, preenche nome e email e adiciona a tua conta em Test users.
  4. Em Credentials → Create credentials → OAuth client ID, escolhe Web application.
  5. Authorized JavaScript origins → adiciona …
  6. Authorized redirect URIs → adiciona …
  7. Copia o Client ID (termina em .apps.googleusercontent.com) para o campo abaixo e guarda.

Usa primary para o calendário principal, ou o ID de outro calendário.

Não é usada na exportação autenticada; fica guardada para leituras públicas.
